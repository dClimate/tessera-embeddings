# context_docs/

Design records and decision rationale for `tessera_embeddings`.

- `decisions/` — Numbered ADR-style records: what was decided, what was
  considered, why. Append-only; supersede with a new record.
- `design/` — Background concept docs that inform multiple decisions.

These docs are reference material for contributors; users of the library
should rely on `README.md` and `docs/` instead.
